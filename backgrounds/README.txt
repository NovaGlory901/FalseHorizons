BACKGROUNDS

Put a picture or an animated GIF in this folder and FalseHorizons uses it as the background: the visuals smear and warp it as they move.
Put in several and it changes between them every 20 seconds (press B for the next one).

Formats: JPEG, PNG, WebP, BMP, GIF (animated too), TGA, PSD, PIC, PNM.
Take a picture out of the folder to stop using it. The program notices new and removed files by itself; no restart needed.
Big pictures are shrunk to fit (1024 pixels on the long side; animations 512). With nothing here the background is plain black.
