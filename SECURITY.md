# Security policy

## Reporting a problem
Please report security problems **privately**, not in a public issue. On GitHub, open this repository's **Security** tab and choose
**Report a vulnerability**. Say what you found, how to reproduce it, and which version and operating system.

This is a one-person, spare-time project, so there is no fixed response time.

## What counts
- A damaged or hostile file (audio, picture, preset or theme) that crashes the program, hangs it or runs code.
- Reading or writing files the program was not asked to open.
- Secrets in the repository or its history.

## Supported versions
Only the latest release receives fixes.
